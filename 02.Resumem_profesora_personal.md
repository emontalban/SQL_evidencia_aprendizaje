## 2. Módulo 1: Aclarando `COUNT()` y `HAVING`
- **`COUNT(*)`**: Cuenta absolutamente todas las filas de un grupo, incluyendo nulos y duplicados.
- **`COUNT(columna)`**: Cuenta únicamente las filas que tienen un valor no nulo en esa columna específica.
- **`WHERE` vs `HAVING`**:
  - `WHERE` actúa antes de que se formen los grupos (filtra filas individuales).
  - `HAVING` actúa después del `GROUP BY` (filtra resultados calculados o agregados, como un `COUNT` o `SUM`).

---

## 3. Módulo 2 y 3: Conexión de Python con SQLite y Pandas
- **SQLite y `sqlite3`**: Módulo integrado en Python para gestionar bases de datos locales en un único archivo (`.db`).
- **El flujo de trabajo en Python**:  
  `1. sqlite3.connect("nombre.db")`  
  `2. conexion.cursor()`  
  `3. cursor.execute(...)` o `cursor.executemany(...)`  
  `4. conexion.commit()` (para guardar cambios de escritura)  
  `5. conexion.close()`  
- **Pandas**: Integración mediante `pd.read_sql_query()` para transformar directamente los resultados de una consulta SQL en un DataFrame de análisis.

## 4. Módulo 4: Proyecto Integrador (Gestión de Pedidos)
Código desarrollado y depurado durante la sesión:

```python
import sqlite3

# 1. Conexión a la base de datos
conexion = sqlite3.connect("tienda.db")
cursor = conexion.cursor()

# 2. Creación de la tabla pedidos
cursor.execute("""
    CREATE TABLE IF NOT EXISTS pedidos (
        id INTEGER PRIMARY KEY,
        cliente TEXT,
        producto TEXT,
        precio REAL
    )
""")

# 3. Inserción múltiple de datos de prueba
sql = "INSERT INTO pedidos (cliente, producto, precio) VALUES (?, ?, ?)"
datos = [
    ("Pepe", "Manzana", 3.00),
    ("Pepe", "Vino", 5.00),
    ("Juan", "Pera", 2.00),
    ("Maria", "Pescado", 3.00),
    ("Ana", "Manzana", 4.00),
    ("Pepe", "Manzana", 3.00),
    ("Pepe", "Vino", 5.00),
    ("Juan", "Pera", 2.00),
    ("Maria", "Pescado", 3.00),
    ("Ana", "Manzana", 4.00),
]
cursor.executemany(sql, datos)
conexion.commit()

# 4. Consulta SQL avanzada con GROUP BY y HAVING
cursor.execute("SELECT producto FROM pedidos GROUP BY producto HAVING COUNT(*) > 1")
resultados = cursor.fetchall()

print("Productos vendidos más de una vez:")
for fila in resultados:
    print(f"- {fila[0]}")

conexion.close()
```
