**Tu tarea:** explica qué hace cada instrucción y cómo se relacionan entre sí. 
| Instrucción | ¿Qué hace? |
|---|---|
| `import sqlite3` | Carga el módulo que permite trabajar con SQLite desde Python. |
| `sqlite3.connect()` | Abre una conexión con una base de datos. Si el archivo indicado no existe, normalmente lo crea. |
| `execute()` | Ejecuta una instrucción SQL, por ejemplo crear una tabla, insertar datos o hacer una consulta. |
| `fetchall()` | Recupera todas las filas pendientes del resultado de la consulta ejecutada. Devuelve una lista de tuplas. |
| `close()` | Cierra el recurso sobre el que se llama. En `conexion.close()`, cierra la conexión con la base de datos. |

La relacion entre ellas es :
1. Primero se importa la libreia (`import sqlite3`)
2. Se establece la conexión al archivo (`sqlite3.connect()`) 
3. Se prepara y ejecuta la orden (`execute()`)
4. Se recogen los datos devueltos (`fetchall()`) 
5. Se cierra la conexión (`close()`).
