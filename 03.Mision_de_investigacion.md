`Es un lenguaje de programacion con el que podemos dar instrucciones, se parece mucho al ingles por ello es muy facil de aprender, sirve para el desarrollo web, analisis de datos y se ha vuelto muy popular en la inteligencia artificial.`

3. ¿Cuál es la diferencia entre una base de datos y un lenguaje de programación?

    `Por ejemplo:`  
    `- La base de datos guarda los productos y sus precios.`  
    `- Python puede recuperar esos precios y calcular el total de una compra.`
